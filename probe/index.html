arena-web relay conformance probe

This page measures the usable routed datagram path between this browser and one game destination behind a compatible WebTransport-to-UDP relay, using the framing fixed in docs/relay-datagram-contract.md and the sizes fixed in locks/relay-measurement-vector.json. It knows nothing about any game.

Every value below is runtime input, and none of it is committed to the repository. The authorization, endpoint, certificate hashes and destination address are secrets or environment detail: they stay in this page, never reach the report, and never reach the log — and neither does the virtual client address the relay assigns. The session settings and the path notes below do travel in the report, which is what they are for. Use a short-lived, single-use authorization: the field is cleared after every attempt, successful or not, so a spent allowance is not reused by accident.
